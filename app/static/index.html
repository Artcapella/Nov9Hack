      What runs NETwork

      elastic

      Elastic Cloud Serverless
      Stores profile records, public profile search, the boundary that keeps contacts private, and connection events.
      Hybrid retrieval
      Combines BM25 keyword matching with semantic_text meaning search using RRF.
      AI / RAG
      Concierge answers are based on the attendee and sponsor records that search returns.
      MCP
      Connects an Elastic Agent Builder agent to a coding-agent host so it can call live tools.
      ES|QL
      Aggregates opt-in activity into conference statistics.

      Command center

      organizer

      Counts and aggregates only. No names, messages or contact details appear here. Topics come from card fields attendees already chose to publish.
