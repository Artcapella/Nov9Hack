      How it fits together

      Elastic Cloud Serverless
      One strict, versioned index per concern: public cards, restricted resume data, encrypted contacts, ingestion queue, introductions and interactions. Contacts never sit in a searchable index.
      Jina embeddings
      semantic_text fields call the pinned Jina v5 endpoint at index time. The 2D and 3D maps read those stored vectors back (_inference_fields) and never re-embed them.
      Hybrid retrieval
      BM25 keyword matching and semantic search fused with RRF. The Ask tab shows all three side by side. Every branch applies the same consent, event and expiry filters.
      Clustering
      k-means (cosine, deterministic k-means++) on the full 1024-d vectors. Each cluster is named after the tags most over-represented among its members compared with the whole room (share × idf).
      Interaction graph
      Links exist only after an interaction: viewed profile (1) < same session (2) < messaged (3) < met in person (5), with a little extra for repeats. Profile views are visible only to the two people involved.
      Agent Builder + MCP
      The concierge answers from approved evidence with three event-scoped ES|QL tools. The same agent is reachable from coding hosts over MCP.
      Dash0
      API and worker export OTLP traces and metrics with no profile content. Queue jobs carry trace context, so a publish spans both processes.
      Radar
      The Helm release runs non-root and read-only on Kubernetes, watched by the Radar agent.
      Gitar
      Every PR gets a privacy-focused review against the repository's own instructions.
